# BigIntensive

This is a project for the "Big Intensive Application and Big Data Exams" of the Studies University of Perugia.

This project gives:

- Kubernetes deployment [k3s/README.md](k3s/README.md).

## What is FitnessHub

This project aim to simulate a fitness application that permit to store workout sessions and running sessions. Every choice has been made considering an a
application with 500'000+ users.
This project is composed by the following components:

- k3s cluster as orchestrator
- React frontend (port 5173)
- Express backend (port 3001)
- Postgresql database (port 5432)
- Clickhouse database (port 8123)
- Kafka message broker (port 9092)
- Spark streaming jobs (port 7077)
- Jupyter notebook for data analysis (port 8888)
- Other scripts for testing and data generation

## Architectur and functionality

### Frontend

The frontend is necessary to show the database sinergy both with Clickhouse and Postgresql.

### Backend

The backend do the following operations:

- Read/Write operation on Postgresql
- Read operation on Clickhouse
- Push events from the script to Kafka
- Simulate Spark jobs activation

### Smartwatch simulator script

Is necessary to simulate user activities and to push them to the backend. A parallel python script is the best choice.

### ELT process script

It's function is to read events from Postgresql and copy them to Clickhouse. It works once a day to synchronize the data between the two databases.

### Postgresql

It store all the data about user information and gym workouts. Citus extension is not the best choice for this project because the volumes of data is not so high.

### Clickhouse

It store all the data about gym workouts and running sessions. It's used for analytics and data analysis. It is a practice known as ELT.

### Kafka

It is used as message broker to store safely all the events generated by the test script.
Kafka stream is used to read events and to push them to Clickhouse. Kafka stream is a good choice because it is fast and distributed.

### Spark

It is used to make data analysis reading data from Clickhouse and Postgresql.

### Jupyter notebook

It allow to show the Spark reports.

### k3s

It is used as orchestrator to manage all the components of the project and scale them if necessary.
